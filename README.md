# Datheon_Machine_Learning_-_Data_Science_Internship

# Machine Learning Projects

This repository contains three machine learning projects completed as part of the **Datheon Machine Learning & Data Science Internship**. These projects demonstrate data preprocessing, exploratory data analysis, feature engineering, model training, and performance evaluation using Python.

## Projects

### 1. Iris Flower Classification
- **Dataset:** Iris Dataset
- **Models:** Logistic Regression and Decision Tree
- **Objective:** Classify iris flowers into three species: Setosa, Versicolor, and Virginica.
- **Evaluation:** Accuracy, Precision, Recall, F1-score, and Confusion Matrix.

### 2. Real Estate Housing Price Prediction
- **Dataset:** California Housing Dataset
- **Models:** Linear Regression, Ridge Regression, and Lasso Regression
- **Objective:** Predict median house values using regression techniques and feature engineering.
- **Evaluation:** RMSE, MAE, and R² Score.

### 3. Predictive Customer Churn Classification
- **Dataset:** Telco Customer Churn Dataset
- **Models:** Random Forest and XGBoost
- **Objective:** Predict customer churn and address class imbalance using class weighting.
- **Evaluation:** Accuracy, Precision, Recall, F1-score, ROC-AUC, and Confusion Matrix.
- **Best ROC-AUC:** 83.55% (XGBoost).
